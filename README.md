# MAMA ❤️ AMMU — Birthday Website

A mobile-first React/Vite single-page experience based on the supplied master prompt.

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

## Build

npm run build

The production files will be generated in `dist/`.

## Edit personal content

Most content is currently kept directly in `src/main.jsx` so this first version is easy to understand and edit. A later pass can move all copy into `src/data/content.js` as requested by the master prompt.

## Media

No photos, stock images, audio, video, or music are included, matching the master prompt.
